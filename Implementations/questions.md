### How do the agents handle missing data?

According to Dr. Nance’s explanation, the agents use a workflow architecture based on “gates” to identify and handle missing data (17:06 - 17:33). The process works as follows:

**Gate Verification:** The coordinator agent (orchestrator) supervises a fleet of agents, and at each stage there is a control mechanism to verify whether the required information is present (17:08).

**Missing Data Flagging:** If critical data is missing, the system stops processing and issues an alert or signal to the clinician (17:26 - 17:30). This ensures that the doctor does not make decisions based on incomplete information or false observations.

**Quality Control:** The system is designed not to be fully autonomous. When evidence from a previous agent is missing, the subsequent agent is instructed to recognize the absence and not proceed, preserving the integrity of the decision-support process (47:04 - 47:48).

**Confidence Index:** In some cases, missing data causes the system’s confidence score to automatically decrease, signaling to the user that the result does not have the complete foundation required for an accurate assessment (47:40 - 47:50).
