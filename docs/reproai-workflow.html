Workflow · seven lanes · runs in prototype · not clinically validated

The machine may draft. A professional decides.

Nine beats across seven lanes, read left to right. Every box says what it reads and what it writes, so nothing has to be inferred. The language model answers from cited passages; the decision model scores from verified inputs, and no language model can call it. A draft waits until a clinician signs it with a note. The bottom lane is the loop that keeps going after release.

THE THREE GATES, IN ORDER

Role, then consent, then data

  • Role — only a clinician with the case on their list can run it
  • Consent — every member must have shared their record; joint work also needs partner consent
  • Data — missing values return insufficient data, never a guess

Any gate fails and nothing is read, nothing is written, and the person is told why.

TWO MODELS, KEPT APART

The language model never computes

The copilot is a language model — Azure OpenAI in UAE North with automatic Groq (US) fallback, at most five turns — that answers from 37 cited passages drawn from five documents: Daman Thiqa v3.6, WHO 2025, ESHRE 2020, the WHO semen manual, and ReproAI's own rules. Retrieval runs on Azure AI Search when configured, otherwise a local BM25 corpus.

The decision model is deterministic. It scores from verified inputs, shows every factor, and is not a tool the language model can call.

THE GATE IS A STEP, NOT A POLICY

Only a clinician can release it

A draft is invisible to the patient. Release and discard both run through one endpoint, both need a note of at least ten characters, and a discard needs a reason. No model call, scheduled job or API route can set a draft to released.

Measured (team-written questions): retrieval hit@4 36/36 · Arabic retrieval 8/8 · end to end on Azure gpt-5-mini (14 Nov): abstains 12/12 · citations resolve 80/80 · sentences supported 72/80. Not yet: time from signal to counselling on real patients.
