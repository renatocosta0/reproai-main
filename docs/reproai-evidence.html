Evidence · Path to pilot

Roadmap to a clinical pilot

Four phases. Each has an exit gate that must be met before the next begins — so readiness is a test, not an opinion.

01Now

Research prototype

Gated assessment, deterministic scoring with Shapley, citation-verified answers, encryption at rest, bilingual portal.

Exit gate

Inspectable flow and tested failure paths

02Co-design

Arabic and clinical review

Native-speaking clinician review of every Arabic string and passage; UAE reference limits; accessibility audit.

Exit gate

Arabic retrieval and copy accepted by a reviewing clinician

03Validate

Measurement and change criteria

Prospective accuracy against local norms, abstention rate, citation validity and performance by subgroup — all prespecified.

Exit gate

Prespecified accuracy met by subgroup

04Pilot

Controlled clinical pilot

Authorised data links, staffed review queue, incident handling, rollback, agreed hosting and data residency.

Exit gate

Safety, referral burden, time to assessment
