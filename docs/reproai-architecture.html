Architecture · System View · Runs in Prototype · Not Clinically Validated Synthetic data only · UAE hosting proposed

The clinician sits inside the pipeline, not beside it.

Seven stages along one clinical spine. Data enters through a 5-purpose consent gate; a deterministic, literature-derived scoring engine (hand-set, not validated) computes per-factor contributions and a model-based interval, or refuses when required inputs are missing; outputs stay in draft until a clinician writes a note and signs off; released results reach the patient portal and can be exported as HL7 FHIR R4. Malaffi import and UAE hosting are proposed for production.

CLINICAL GOVERNANCE ON THE SPINE

The Gate is a Step, Not a Policy

Stage six is the only route from a draft to a patient. In code, the assessment pipeline has no function to set a prediction status to RELEASED. The release endpoint strictly requires an authenticated clinician session, a verified patient link, and a rationale note of at least 10 characters.

MATHEMATICAL EXPLAINABILITY

Two Engines, Strictly Kept Apart

ReproAI strictly separates mathematical prediction from natural language copilot:

  • Literature-spline v2.2: Deterministic, hand-set scoring shaped on published curves (not trained or validated), with per-factor contributions and a model-based 95% interval. If a required biomarker is missing, it refuses to guess.
  • Azure OpenAI gpt-5-mini (UAE North): Language model copilot grounded in Daman Thiqa ART v3.6, WHO, and ESHRE guidelines. It cannot alter or generate risk scores.

HOSTING & DATA SECURITY

What runs today, and what production needs

Prototype on synthetic data; production steps toward DoH data-governance requirements:

  • UAE residency (proposed): the LLM already runs on Azure OpenAI in UAE North; production moves the app, database and scoring service there too and removes the Groq (US) fallback. Today the database is in the US.
  • AES-256-GCM at rest: a Prisma extension encrypts names, medical history, clinician notes, assessment inputs and factors, and chat before writing to PostgreSQL (unit-tested). Numeric lab values and emails are not yet encrypted; the key is not yet in a managed vault.
  • HL7 FHIR R4: export of Patient, Observation and RiskAssessment runs today; Malaffi import is proposed.
